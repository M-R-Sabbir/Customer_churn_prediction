# Customer Churn Prediction

## Problem Statement

The goal of this project is to predict whether a customer
will churn based on their demographic information,
subscription details, and service usage.

## Objective

Build an end-to-end machine learning system that covers:

- Data analysis
- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Experiment tracking
- Model serving
- API development
- Dockerization
- Testing
- CI/CD
- Deployment

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- MLflow
- FastAPI
- Docker
- GitHub Actions
